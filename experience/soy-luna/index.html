Comment jouer

Joystick vers le haut pour pousser, gauche/droite pour tourner, vers le bas pour freiner. Maintiens Saut : tout droit = tour de lune ; droite = étoile ; gauche = arabesque ; Élan + Saut à grande vitesse = croisé. Sur un battement, Élan + Saut rapide déclenche la figure du rythme. Relâche le joystick pour glisser, pousse vers le bas pour freiner. Trois roses se cachent sur les côtés. Les balanciers se contournent ou se sautent. Au clavier : flèches ou ZQSD/WASD, Espace et Maj.

Sur iPhone : Safari → Partager → Sur l'écran d'accueil, si cette option est proposée.

Scène de développement : personnage et rendu encore à valider. Les sauvegardes classiques restent séparées.
